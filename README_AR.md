# Food Inspector Pro — مفتش الأغذية الذكي

## ما الذي تتضمنه هذه الحزمة؟
- مشروع Flutter مصدر قابل للتطوير لتطبيق Android بواجهة عربية من اليمين إلى اليسار.
- قاعدة بيانات SQLite محلية تعمل دون إنترنت.
- سجلات قابلة للإضافة والتعديل والحذف والبحث: المنشآت، الزيارات التفتيشية، المخالفات، العينات، والمواعيد.
- نسخة احتياطية JSON قابلة للمشاركة، واستعادة نسخة احتياطية مع تأكيد قبل استبدال السجلات.
- بنية بيانات بإصدار مخطط `schemaVersion` لتسهيل تطوير الترحيل والمزامنة مستقبلًا.

## التشغيل
1. ثبّت Flutter SDK وAndroid Studio على جهاز كمبيوتر.
2. فك ضغط الحزمة وافتح مجلد `food_inspector_flutter` في Android Studio أو VS Code.
3. نفّذ من الطرفية داخل المجلد:
   ```bash
   flutter pub get
   flutter run
   ```
4. لإنشاء APK تجريبي:
   ```bash
   flutter build apk --debug
   ```
   سيظهر الملف عادةً في `build/app/outputs/flutter-apk/app-debug.apk`.

## ملاحظات مهمة
- لم يتم إنشاء APK داخل بيئة العمل الحالية لعدم توفر Flutter/Dart/Android SDK هنا؛ هذه حزمة مصدر وليست ملف APK مثبتًا.
- لا توجد مزامنة سحابية مفعلة حاليًا. يلزم لاحقًا اختيار خدمة وهوية دخول وسياسة تعارضات قبل توصيل أي مزامنة.
- النسخة الحالية لا تتضمن إرفاق صور، إشعارات مجدولة، تصدير Excel، أو مساعد ذكاء اصطناعي؛ هذه مراحل تالية وليست وظائف مكتملة في هذا الإصدار.
- احتفظ بنسخة احتياطية خارج الهاتف بانتظام. حذف التطبيق أو مسح بياناته قد يحذف قاعدة البيانات المحلية.
- سجلات الزيارات والمخالفات أداة توثيق مساعدة، وليست بديلًا عن النماذج الرسمية أو الإجراءات المعتمدة لدى جهة العمل.

## إنشاء ملفات Android بعد فك الضغط
لأن الحزمة تُسلَّم كمصدر خفيف دون ملفات Gradle المولّدة، افتح الطرفية داخل المجلد ونفّذ مرة واحدة:
```bash
flutter create --platforms=android .
flutter pub get
flutter run
```
إذا أنشأت الأمر ملفات `lib/main.dart` أو `pubspec.yaml` بديلة، احتفظ بالنسخ المرفقة واستعدها قبل التشغيل.
